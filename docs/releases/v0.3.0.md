## Linux support

This release adds native Linux DDC/CI control, X11 global shortcuts, a tray icon,
and a GTK settings window for the ASUS ROG Strix OLED XG32UCWMG.

- Default shortcuts: **Ctrl+Win/Super+Arrow**. Right opens Input Select or
  confirms; Up/Down navigate; Left cancels.
- Settings lets you select Ctrl, Alt, Shift, and Win/Super modifiers and toggle
  per-user login autostart. Changes apply immediately.
- Cinnamon shortcut conflicts are checked before saving. Failed changes restore
  the previous configuration.
- The tray menu offers Settings, Rescan monitor, and Exit. Starting the app again
  opens the existing instance's settings.
- Tested on Linux Mint 22.3 Cinnamon/X11 with successful switching to another
  monitor input and back.

### Linux x86-64 installation

Download **rog-osd-switch-linux-x64.tar.gz**, then:

```sh
tar -xzf rog-osd-switch-linux-x64.tar.gz
cd rog-osd-switch-linux-x64
./scripts/install-linux.sh
~/.local/bin/rog-osd-switch-start
```

The compiled backend is included; Rust is not required to install this package.
The installer needs no sudo and enables login autostart on first installation.
Saved shortcuts and autostart preferences are preserved on upgrades. Exit an
existing tray instance before upgrading.

Runtime requirements: X11, libX11, Python 3, PyGObject/GTK 3, and read/write access
to the display's `/dev/i2c-N` device. Ayatana AppIndicator is preferred for the
tray. Linux Mint 22.3 already included these GUI dependencies. Debian/Ubuntu
packages are `python3-gi`, `gir1.2-gtk-3.0`, and
`gir1.2-ayatanaappindicator3-0.1`. Global shortcuts on Wayland are not yet
supported; the backend's `--probe` and `--send` commands work independently.

### Windows

Download **rog-osd-switch.exe**. Existing Windows tray functionality and default
Ctrl+Alt+Arrow shortcuts are retained.

**SHA256SUMS** contains checksums for both downloads. The automatically generated
source archives contain the source code, not the prebuilt Linux installation.
